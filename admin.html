Как добавить новость

  1. Создайте папку: static/img/rsci/news/ДАТА/
  2. Загрузите туда фото (например: 01.jpg, 02.jpg, 03.jpg)
  3. Укажите название папки (по умолчанию -- дата новости)
  4. Введите список фото (только имена, по одному на строку)
  5. Заполните остальные поля и нажмите "Сгенерировать JSON"
  6. Скопируйте JSON и вставьте в news.json
